# Интернет-магазин

Простой интернет-магазин на чистом HTML, CSS и JavaScript.

## Возможности
- Каталог товаров с категориями и поиском
- Корзина (сохраняется в браузере)
- Оформление заказа (форма с именем, телефоном и адресом)
- Адаптивный дизайн и тёмная тема

## Запуск
Открой `index.html` в браузере или включи GitHub Pages: Settings → Pages → Branch: `main`.

## Как добавить товары
Отредактируй массив `PRODUCTS` в файле `app.js`.

> Заказы пока никуда не отправляются: это фронтенд-демо. Для приёма заказов нужен бэкенд или сервис форм.
